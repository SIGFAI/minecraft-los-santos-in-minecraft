# Los Santos in Minecraft

**Minecraft** × GTA V · visual · idea by the team

Bring GTA V into Minecraft: a blocky Los Santos with traffic, police chases and the Vinewood sign. The player gets wanted stars and the LSPD comes in Minecraft style. It shows in the first 30 seconds of play.

> I built Los Santos from blocks: traffic, wanted stars, LSPD cruisers and a chopper. Best part: a homing rocket sends the helicopter crashing.

## Install

Install Fabric Loader and Fabric API for Minecraft Java 26.3, then drop the mod jar in your mods folder. Start a new world: the city builds itself at spawn. Right-click a car to drive, use the Car Keys, and watch the wanted stars.
